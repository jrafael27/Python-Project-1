# Ringkasan Penjualan

Aplikasi Python untuk mengolah data penjualan produk.

## Fitur
- Membaca data JSON.
- Menggunakan OOP dan dataclass.
- Menghitung omzet setiap produk.
- Menghitung total omzet.
- Mencari produk terlaris.
- Mengambil kurs USD/IDR dari API.
- Menyimpan hasil ke JSON.

## Cara menjalankan

1. Install dependency:
   pip install -r requirements.txt

2. Jalankan:
   python main.py

3. Hasil tersedia di ringkasan.json.
